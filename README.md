# Search Probes

A No Man's Sky mod for searching generated systems, planets, and fauna without visiting them.

---

</div>

Search results include portal coordinates and can be used for in-game navigation. Open the overlay
with **Ctrl + comma** by default. If a configured binding becomes unusable, use
**Ctrl + Shift + Backspace** to recover it.
